02 / DEVELOPER GUIDE

Integrate your app

Connect your own backend or bot in a few steps. Keep your API key on the server—never expose it in browser JavaScript, public repositories, or client-side apps.

1

Create an API key

Open the Admin panel, sign in, go to API keys, enter an app label, and generate a key. Copy it immediately; it is shown only once.

2

Check available inventory

Call this endpoint from your backend. The response contains inventory IDs and number status—not OTP values.

GET https://YOUR-DOMAIN/api/numbers/available
X-API-Key: YOUR_API_KEY
3

Reserve a number

Send the selected inventory ID as JSON. A successful request returns an order ID and the reserved number.

POST https://YOUR-DOMAIN/api/numbers/reserve
Content-Type: application/json
X-API-Key: YOUR_API_KEY

{
  "number_id": "NUMBER_ID_FROM_AVAILABLE"
}
4

Check order status

Use the order ID returned by the reserve request.

GET https://YOUR-DOMAIN/api/orders/ORDER_ID
X-API-Key: YOUR_API_KEY

Example — Python backend

import requests

BASE_URL = "https://YOUR-DOMAIN"
API_KEY = "YOUR_API_KEY"
HEADERS = {"X-API-Key": API_KEY}

response = requests.get(
    f"{BASE_URL}/api/numbers/available",
    headers=HEADERS,
    timeout=15
)
response.raise_for_status()
numbers = response.json()["numbers"]

if numbers:
    result = requests.post(
        f"{BASE_URL}/api/numbers/reserve",
        headers={**HEADERS, "Content-Type": "application/json"},
        json={"number_id": numbers[0]["id"]},
        timeout=15
    )
    result.raise_for_status()
    print(result.json())

Example — JavaScript backend (Node.js)

const BASE_URL = "https://YOUR-DOMAIN";
const API_KEY = process.env.NUMBERHUB_API_KEY;

const response = await fetch(
  `${BASE_URL}/api/numbers/available`,
  { headers: { "X-API-Key": API_KEY } }
);

if (!response.ok) throw new Error(`HTTP ${response.status}`);
const data = await response.json();
console.log(data.numbers);
Security & OTP handling

Use NumberHub only for numbers and verification flows you are authorized to manage. OTPs must be tied to a specific, authorized verification challenge and delivered only to its intended recipient. This inventory API does not expose a general “get OTP by phone number” endpoint or bulk OTP export.

Replace YOUR-DOMAIN with your deployed domain and store the API key in a server-side environment variable.
